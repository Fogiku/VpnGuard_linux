# Развёртывание VpnGuard

## Установка на существующую Ubuntu

Из корня репозитория соберите агент командой `go build -o bin/vpnguard .`.
Сценарий `deploy/install.sh` устанавливает системные зависимости, включает маршрутизацию IPv4 и запускает службу VpnGuard через systemd.

## Тесты сценариев развёртывания

Из корня проекта:


```sh
python -m unittest discover -s deploy
```

## Выпуск обновления

В чистой копии исходников с тегом `vX.Y.Z`, соответствующим константе Version, выполните `python3 deploy/build_release.py /путь/к/копии-ветки-releases` с Python 3.9+ и Go. Команда собирает бинарники для Linux amd64 и arm64 и записывает манифест с их SHA‑256 и коммитом исходников. В репозитории сборок закоммитьте эти три файла и присвойте коммиту тег `bin-vX.Y.Z`. При публикации отправьте тег сборок и ветку `releases` одной командой `git push --atomic origin HEAD:releases bin-vX.Y.Z`. Исходный тег должен быть доступен на GitHub к моменту публикации.
