# Развёртывание VpnGuard

## Установка на существующую Ubuntu

Из корня репозитория соберите агент командой `go build -o bin/vpnguard .`.
Сценарий `deploy/install.sh` устанавливает системные зависимости, включает маршрутизацию IPv4 и запускает службу VpnGuard через systemd.

## Установочный USB

`build_bundle.py` готовит файлы комплекта. Параметры доступны через `python deploy/build_bundle.py --help`.
Для этого сценария нужны Go, Python, OpenSSH и OpenSSL. Сценарий скачивает пакеты MeduzaVPN и zapret2 и проверяет их контрольные суммы.

`Prepare-Usb.ps1` записывает комплект на USB с установщиком Ubuntu. На исходном шлюзе Windows `START-INSTALL.cmd` собирает конфигурацию и назначает однократную загрузку с USB. Установка Ubuntu с этого носителя может стереть выбранный диск. Сверьте диск и сетевые настройки перед подтверждением установки.

Проверки установочной среды по SSH выполняет `verify_installer_ssh.py`. Файлы доступа, дампы, журналы установщика и снимки настроек храните вне Git.

## Тесты сценариев развёртывания

Из корня проекта:
Для тестов проверки SSH установите пакет `paramiko` в виртуальное окружение Python.

```sh
python -m unittest discover -s deploy
```
